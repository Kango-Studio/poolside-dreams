# SJ Pools & Landscaping

Website for [SJ Pools & Landscaping](https://sjpoolsandlandscaping.com/), a New Jersey pool
construction and landscape design company. Home, Services, Projects, About and Contact pages,
built with a Bentley-style hero carousel, 3D hover effects and fade-in reveals.

## Development

This project uses [Bun](https://bun.sh).

```sh
bun install
bun run dev
```
